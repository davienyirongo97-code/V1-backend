# Backend

Owner: backend dev

This folder will contain the server-side API for the MANEB results portal.

## Planned endpoints

- `GET /api/results?examNumber=&dob=` — fetch student results
- `POST /api/admin/login` — admin authentication
- `GET /api/admin/stats` — server load stats
